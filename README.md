# TicTacToe AI

Крестики-нолики с AI на алгоритме Minimax.

## Команда
| Участник | Роль |
|---|---|
| Глеб | Project Lead / AI |
| Евгений | Frontend / UI |
| Стас | Logic & Algorithm |
| Алекс | QA / Docs |

## Технологии
- Kotlin
- Android (minSdk 24)
- Minimax + Alpha-Beta
- Kotlin Coroutines
- JUnit 4

## Как запустить
1. Клонировать репо
2. Открыть в Android Studio
3. Нажать Run (Shift+F10)
